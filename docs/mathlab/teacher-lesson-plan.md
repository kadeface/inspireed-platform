## TV-1 · 两地相向而行

| 项目 | 内容 |
|------|------|
| **任务 ID** | `tv_meet1` |
| **学段** | 初中 7 年级 |
| **课时** | 40′ |
| **学生手册** | 学生手册 · TV-1 |
| **前置** | 速度、路程、时间 |

### 教学目标

| 维度 | 目标 |
|------|------|
| 知识与技能 | 理解 $t=S/(v_1+v_2)$；会用双车并行积木；读 s-t 交点 |
| 过程与方法 | 预测—编程—验证 |
| 情感态度 | 建模意识；图象辅助计算 |

### 教学重难点

- **重点**：相向而行速度相加；s-t 交点 = 相遇时刻  
- **难点**：双车路程与总间距守恒的关系  

### 教学过程

| 阶段 | 时间 | 教师活动 | 学生活动 | 设计意图 |
|------|------|----------|----------|----------|
| 导入 | 5′ | 出示双城相距 100 cm 情境，问「何时相遇」 | 口算 $t=4$ s | 激活 prior knowledge |
| 演示 | 5′ | 深链 `?task=tv_meet1`；加载示例→运行；指 s-t 交点 | 观察轨迹与图象 | 建立成功标准 |
| 探究 | 20′ | 巡视；提示 `control_parallel_move` | 填学生手册表 1、表 2；改 v₂ 预测 | 做中学 |
| 分享 | 8′ | 板书 $t=S/(v_1+v_2)$；对比两组数据 | 汇报预测与仿真 | 归纳 |
| 拓展 | 2′ | 布置 `tv_meet3` 或提高挑战 | 自评四勾 | 分层 |

### 板书 / 核心句

> 相向而行 → 速度**相加**；s-t 图**交点** → 相遇时刻。

### 备课参数（sceneConfig）

- 甲：0 cm，10 cm/s；乙：100 cm，15 cm/s，face 180°  
- `meetValidate` 容差 5 cm；`stGraph.showBoth: true`

### 易错点

| 现象 | 对策 |
|------|------|
| 混淆相遇与追及公式 | 对比 TV-3，板书「加/减」对照 |
| 只跑演示不口算 | 导入必须先算再验证 |
| 读错 s-t 交点 | 用不同颜色指两线 |

### 评价量规

| 指标 | 4 | 3 | 2 | 1 |
|------|---|---|---|---|
| 公式应用 | 推导并解释 | 公式正确 | 思路对式错 | 无法列式 |
| 编程 | 独立改参运行 | 提示下成功 | 仅演示 | 未运行 |
| 图象解读 | 交点+意义 | 能读交点 | 偏差 | 不会 |
| 合作 | 清晰汇报 | 能汇报 | 参与 | 未参与 |

## TV-2 · 乙车延迟出发

| 项目 | 内容 |
|------|------|
| **任务 ID** | `tv_meet3` |
| **学段** | 初中 7–8 |
| **学生手册** | 学生手册 · TV-2 |

### 教学目标

理解分段 s-t；「先走段 + 同走段」分析；等待 + 并行积木。

### 教学重难点

- **重点**：非同时起步的分段分析  
- **难点**：第二阶段相遇时刻计算  

### 教学过程要点

1. 与 TV-1 对比 s-t 图（5′）  
2. 画两阶段示意图（8′）  
3. 运行 `travelDelayStart` 程序（20′）  
4. 写 3 句对比结论（7′）  

### 易错点

把延迟时间直接加在相遇时间上而不分段。

### 评价量规

同 TV-1，增加「分段分析」：能否区分 0–2 s 与 2 s 后。

## TV-3 · 同向追及

| 项目 | 内容 |
|------|------|
| **任务 ID** | `tv_chase1` |
| **学段** | 初中 8 |
| **学生手册** | 学生手册 · TV-3 |

### 教学目标

理解 $t=\Delta s/(v_2-v_1)$；追及 = 速度**相减**；联系 `fg_l3_3`、`calc_l2_3`。

### 教学重难点

- **重点**：追及与相遇公式对比  
- **难点**：s-t 两线交点在追及中的意义  

### 教学过程要点

1. 并排展示 TV-1 与 TV-3 的 s-t 图  
2. 口算 $t=40/6\approx 6.67$ s  
3. 讨论「快车 10 cm/s 能否追上」  
4. 布置统一模型一句话总结  

### 板书

| 类型 | 公式 | 速度关系 |
|------|------|----------|
| 相遇 | $t=S/(v_1+v_2)$ | 相加 |
| 追及 | $t=\Delta s/(v_2-v_1)$ | 相减 |

---

## CALC-2 · s-t 图的斜率

| **任务 ID** | `calc_l2_1` | **学段** | 初中 8 |
| **学生手册** | 学生手册 · CALC-2 |

### 教学目标

s=vt；s-t 斜率 = v；calcValidate slope。

### 教学重难点

- **重点**：Δs/Δt 与速度数值相等  
- **难点**：割线叠加层的读法  

### 备课参数

`calcValidate: { type: 'slope', t0: 0, t1: 5, expected: 5 }`

### 核心句

> s-t 图**越陡** → 走得**越快** → **斜率**就是速度。
