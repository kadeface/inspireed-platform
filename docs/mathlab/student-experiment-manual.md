# 轮式机器人虚拟课程 · 学生实验手册

**版本**：v2.0  
**适用读者**：小学生、初中生  
**平台**：MathLab 虚拟仿真（Blockly 拖拽编程）  
**覆盖学段**：小学 5–6 年级 · 初中 7–9 年级

---

## 如何使用本手册

1. 打开浏览器，进入 MathLab（教师会提供链接）。  
2. 在左侧选择 **学段 → 任务**，或请教师给出任务编号（如 `fg_l2_1`）。  
3. 阅读本课 **任务情境**，按 **实验步骤** 操作。  
4. 把数据填进 **记录表**。  
5. 完成后对照 **自我检查** 打勾。

### 打开指定任务

在地址后加上：`?task=任务编号`  

示例：`/mathlab/index.html?task=fg_l2_1`

### 三条学习路线

| 路线 | 你会学到 |
|------|----------|
| 行程问题 | 相遇、追及、路程与时间 |
| 函数图像 | 坐标、描点、函数图象 |
| 微积分直觉 | 快慢变化、斜率、面积与累积 |

---

## 实验课怎么上（40 分钟）

| 时段 | 你要做什么 |
|------|------------|
| 开头 5′ | 听情境，先猜答案 |
| 接下来 5′ | 看老师演示，知道「做对了」是什么样 |
| 中间 20′ | 两人一组：一人编程，一人填表 |
| 然后 8′ | 汇报：你的预测和仿真一样吗 |
| 最后 2′ | 自评：基础 / 提高 / 拓展完成了吗 |

## TV-1 · 两地相向而行（相遇）

**任务编号**：`tv_meet1`  
**适合年级**：初中 7 年级  
**用时**：约 40 分钟

### 我能学到

- 两车相向而行时，相遇时间 $t = S \div (v_1 + v_2)$  
- 用程序控制两辆车同时出发  
- 从 s-t 图上读出相遇时刻  

### 任务情境

A、B 两城相距 **100 cm**。甲车从 A 以 **10 cm/s** 出发，乙车从 B 以 **15 cm/s** **相向**出发。

**请完成**：先算何时相遇，再编程验证，并读 s-t 图上的交点。

### 实验步骤

1. 打开任务 `tv_meet1`。  
2. **口算**：$t = 100 \div (10 + 15) =$ ______ s  
3. 点击「加载示例程序」→「运行」，看两车在哪里相遇。  
4. 看 s-t 图，找到两条线的**交点**，记录时刻。  
5. （提高）把乙车速度改成 20 cm/s，再算、再验证。

### 数据记录表

**表 1 · 相遇记录**

| 间距 S | v₁ | v₂ | 我算的 t | 仿真 t | 相遇位置 | □通过 |
|--------|-----|-----|----------|--------|----------|-------|
| 100 cm | 10 | 15 | | | | |
| 100 cm | 10 | 20 | | | | |

**表 2 · s-t 图读点**

| 时刻 t (s) | 甲车路程 | 乙车路程 | s₁+s₂ 等于 100 吗 |
|------------|----------|----------|-------------------|
| 0 | | | |
| 4 | | | |

### 挑战任务

| 级别 | 任务 |
|------|------|
| ★ 基础 | 默认参数验证通过 |
| ★★ 提高 | 乙车 20 cm/s，预测与仿真误差 < 0.5 s |
| ★★★ 拓展 | 完成 `tv_meet3`（乙车延迟 2 s 出发） |

### 自我检查

- □ 我能说出相遇公式  
- □ 程序能运行，两车相遇  
- □ s-t 交点与计算一致  
- □ 我能解释「相向要速度相加」

## TV-3 · 同向追及

**任务编号**：`tv_chase1`  
**适合年级**：初中 8 年级

### 我能学到

- 追及时间 $t = \Delta s \div (v_\text{快} - v_\text{慢})$  
- 追及要速度**相减**，相遇要**相加**  

### 任务情境

慢车 8 cm/s 在前，快车 14 cm/s 在后，相距 40 cm。何时追上？

### 实验步骤

1. 口算：$t = 40 \div (14 - 8) \approx$ ______ s  
2. 运行 `tv_chase1`，读 s-t 交点。  
3. 思考：若快车只有 10 cm/s，还能追上吗？

### 数据记录表

| Δs | v快 | v慢 | 预测 t | 仿真 t | 追及位置 |
|----|-----|-----|--------|--------|----------|
| 40 cm | 14 | 8 | | | |

### 挑战任务

- ★★★ 写 100 字：相遇和追及有什么不同  

### 自我检查

- □ 能区分「相加」和「相减」  
- □ 验证通过

**适合年级**：初中 8 年级
